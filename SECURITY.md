# Security policy

## Supported versions

Security fixes are applied to the latest published version.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting
feature on this repository. If that option is unavailable, email
abdellahi@student.dei.uc.pt with:

- The affected version
- Steps to reproduce the issue
- The impact you expect
- Any suggested fix or mitigation

You should receive an acknowledgment within seven days. Please allow time for a
fix to be prepared before publishing details.
