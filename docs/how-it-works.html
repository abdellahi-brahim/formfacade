How it works

Your form.
Mapped automatically.

Give FormFacade a published Google Form URL. It finds every field and gives you the mapping for your own UI.

Install

Terminalnpm
npm install @abdellahi/formfacade

Connect the form

  1. Publish your Google Form.
  2. Copy its public viewform URL.
  3. Run the inspector.
  4. Paste the generated fieldMap into your component.
TerminalInspect 
npx @abdellahi/formfacade inspect "YOUR_GOOGLE_FORM_URL"
WaitlistForm.tsxReact 
import { useGoogleForm } from "@abdellahi/formfacade";

const { submit, isSubmitting, isSuccess } = useGoogleForm({
  formUrl: "https://docs.google.com/forms/d/e/.../viewform",
  fieldMap: {
    email: "entry.123456",
  },
});

await submit({ email });

Note: FormFacade sends the request from the browser. Google does not expose a readable cross-origin response, so delivery cannot be confirmed from client-side code.

Give it to your coding agent

Give the agent a published Google Form and the component you want connected. It can resolve the entry IDs and build the mapping.
