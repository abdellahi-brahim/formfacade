How it works

Your fields.
Google's entry IDs.

Create a Google Form, find each field's entry.* ID, and map it to the names used by your React form.

Install

Terminalnpm
npm install @abdellahi/formfacade

Connect the form

  1. Publish your Google Form.
  2. Copy its public viewform URL.
  3. Find the entry.* ID for each question.
  4. Map those IDs in fieldMap.
WaitlistForm.tsxReact
import { useGoogleForm } from "@abdellahi/formfacade";

const { submit, isSubmitting, isSuccess } = useGoogleForm({
  formUrl: "https://docs.google.com/forms/d/e/.../viewform",
  fieldMap: {
    email: "entry.123456",
  },
});

await submit({ email });

Note: FormFacade sends the request from the browser. Google does not expose a readable cross-origin response, so delivery cannot be confirmed from client-side code.
