How you use it

  1. Create a Google Form for the answers you need.
  2. Build the form UI in your React app.
  3. Map your field names to Google's entry IDs.
  4. Call submit(values) from your submit handler.

Note: Short forms should stay short. Use the Typeform pattern only when a longer survey benefits from one question at a time.
